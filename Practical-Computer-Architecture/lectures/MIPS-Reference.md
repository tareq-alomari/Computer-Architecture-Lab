# مرجع MIPS الشامل — دليل سريع لهيكل البرنامج، البيانات، المسجلات، والأوامر

---

## 1. هيكل برنامج MIPS

أي برنامج MIPS يتكون من **قسمين رئيسيين**:

```
# تعليقات — يهملها الـ Assembler

.data
    # قسم البيانات: تعريف المتغيرات والسلاسل النصية
    # كل ما هنا يُخزَّن في RAM

.text
    # قسم الكود: التعليمات البرمجية
    # كل ما هنا ينفذه المعالج (CPU)
    # يبدأ التنفيذ من label المسمى main:
main:
    # التعليمات هنا
```

### مثال كامل:

```mips
.data
    msg: .asciiz "Hello\n"
    x:   .word 42

.text
main:
    la $a0, msg
    li $v0, 4
    syscall
    li $v0, 10
    syscall
```

### مقارنة مع C++:

| MIPS | C++ |
|------|-----|
| `.data` | المتغيرات العامة (global) |
| `.text` | دالة `main()` |
| `main:` | `int main()` |
| `# تعليق` | `// تعليق` |
| label + `:` | اسم دالة أو متغير |

## 2. أنواع البيانات (Data Types) في MIPS

| التوجيه (Directive) | المعنى | الحجم | مثال | C++ مقابل |
|---------------------|--------|-------|------|-----------|
| `.word n` | عدد صحيح (32 bit) | 4 بايت | `x: .word 10` | `int x = 10;` |
| `.half n` | عدد صحيح (16 bit) | 2 بايت | `y: .half 5` | `short y = 5;` |
| `.byte n` | عدد صحيح (8 bit) | 1 بايت | `z: .byte 3` | `char z = 3;` |
| `.asciiz "str"` | نص منتهي بـ `\0` | متغير | `s: .asciiz "Hi"` | `char s[] = "Hi";` |
| `.ascii "str"` | نص بدون `\0` | متغير | `t: .ascii "Hi"` | `char t[] = {'H','i'};` |
| `.space n` | مساحة فارغة (n بايت) | n بايت | `arr: .space 20` | `int arr[5];` |
| `.float f` | عدد كسري (32 bit) | 4 بايت | `f: .float 3.14` | `float f = 3.14;` |
| `.double d` | عدد كسري (64 bit) | 8 بايت | `d: .double 3.14` | `double d = 3.14;` |

### ملاحظات مهمة:

- **`.word` الأكثر استخداماً** — للأعداد الصحيحة والعناوين
- **`.asciiz`** — النص الذي نطبعه بـ `syscall 4` (يجب أن ينتهي بـ `\0`)
- **`.space`** — للمصفوفات (نحجز مساحة ونملؤها بالبرنامج)
- **Label** (مثل `x:`, `msg:`) هو عنوان (عنوان) في الذاكرة، وليس قيمة

## 3. المسجلات (Registers)

لدينا **32 مسجلاً** في MIPS، كل واحد **32 bit**. أسماؤها ورموزها ووظائفها:

### المسجلات المؤقتة (Temporary) — `$t0` إلى `$t9`

| المسجل | الرقم | الاستخدام | C++ مقابل |
|--------|-------|-----------|-----------|
| `$t0` | 8 | متغير مؤقت | `int t0;` |
| `$t1` | 9 | متغير مؤقت | `int t1;` |
| ... | ... | ... | ... |
| `$t9` | 25 | متغير مؤقت | `int t9;` |

- **تتغير بعد استدعاء دالة** — لا تعتمد عليها أن تبقى كما هي

### المسجلات المحفوظة (Saved) — `$s0` إلى `$s7`

| المسجل | الرقم | الاستخدام | C++ مقابل |
|--------|-------|-----------|-----------|
| `$s0` | 16 | متغير محفوظ | متغير ثابت في الدالة |
| ... | ... | ... | ... |
| `$s7` | 23 | متغير محفوظ | متغير ثابت في الدالة |

- **تبقى محفوظة** بعد استدعاء دالة

### مسجلات المعاملات والنتائج (Argument/Value)

| المسجل | الرقم | الاستخدام | C++ مقابل |
|--------|-------|-----------|-----------|
| `$a0` | 4 | أول معامل للدالة | argument 1 |
| `$a1` | 5 | ثاني معامل | argument 2 |
| `$a2` | 6 | ثالث معامل | argument 3 |
| `$a3` | 7 | رابع معامل | argument 4 |
| `$v0` | 2 | قيمة الإرجاع + رقم syscall | `return value` |
| `$v1` | 3 | قيمة إرجاع ثانية | `return value 2` |

### مسجلات خاصة

| المسجل | الرقم | الاستخدام | الشرح |
|--------|-------|-----------|-------|
| `$zero` | 0 | القيمة صفر دائماً | قراءة فقط = 0 |
| `$sp` | 29 | Stack Pointer | مؤشر المكدس |
| `$ra` | 31 | Return Address | عنوان الرجوع من دالة |
| `$fp` | 30 | Frame Pointer | مؤشر الإطار (اختياري) |
| `$gp` | 28 | Global Pointer | مؤشر المتغيرات العامة |
| `$at` | 1 | Assembler Temporary | يستخدمه الـ Assembler داخلياً |
| `$k0`, `$k1` | 26, 27 | Kernel | لنظام التشغيل فقط |

### ملخص سريع للمسجلات الأساسية:

```
$zero → 0        (ثابت)
$t0-$t9          (مؤقت - لا تضمن بقاءه)
$s0-$s7          (محفوظ - يضمن بقاءه)
$a0-$a3          (معاملات الدالة)
$v0-$v1          (قيمة الإرجاع + رقم syscall)
$sp              (مؤشر المكدس)
$ra              (عنوان الرجوع)
```

## 4. جميع الأوامر (Instructions) المستخدمة — مرتبة حسب النوع

### 4.1. تحميل القيم (Load Immediate / Address)

| الأمر | المعنى | مثال | C++ مقابل |
|-------|--------|------|-----------|
| `li $t, n` | ضع الرقم n مباشرة في المسجل | `li $t0, 5` | `t0 = 5;` |
| `la $t, label` | ضع عنوان label في المسجل | `la $t0, msg` | `t0 = &msg;` |
| `move $d, $s` | انسخ قيمة من مسجل إلى آخر | `move $t0, $t1` | `t0 = t1;` |

### 4.2. العمليات الحسابية (Arithmetic)

| الأمر | المعنى | مثال | C++ مقابل |
|-------|--------|------|-----------|
| `add $d, $a, $b` | جمع | `add $t2, $t0, $t1` | `t2 = t0 + t1;` |
| `sub $d, $a, $b` | طرح | `sub $t2, $t0, $t1` | `t2 = t0 - t1;` |
| `addi $t, $s, n` | جمع مع ثابت | `addi $t0, $t0, 1` | `t0 += 1;` |
| `mul $d, $a, $b` | ضرب | `mul $t2, $t0, $t1` | `t2 = t0 * t1;` |
| `div $a, $b` | قسمة (ناتج في LO, باقي في HI) | `div $t0, $t1` | `t0 / t1` |
| `mflo $d` | انقل من LO (ناتج القسمة) | `mflo $t2` | `t2 = LO;` |
| `mfhi $d` | انقل من HI (باقي القسمة) | `mfhi $t3` | `t3 = HI;` |
| `rem $d, $a, $b` | باقي القسمة (اختصار لـ div+mfhi) | `rem $t2, $t0, $t1` | `t2 = t0 % t1;` |
| `abs $d, $s` | القيمة المطلقة | `abs $t2, $t0` | `t2 = abs(t0);` |
| `neg $d, $s` | عكس الإشارة | `neg $t2, $t0` | `t2 = -t0;` |

### 4.3. العمليات المنطقية وإزاحة البتات (Logical & Shift)

| الأمر | المعنى | مثال | C++ مقابل |
|-------|--------|------|-----------|
| `and $d, $a, $b` | AND على مستوى البتات | `and $t2, $t0, $t1` | `t2 = t0 & t1;` |
| `andi $t, $s, n` | AND مع ثابت | `andi $t1, $t0, 0xFF` | `t1 = t0 & 0xFF;` |
| `or $d, $a, $b` | OR على مستوى البتات | `or $t2, $t0, $t1` | `t2 = t0 \| t1;` |
| `ori $t, $s, n` | OR مع ثابت | `ori $t1, $t0, 0xFF` | `t1 = t0 \| 0xFF;` |
| `xor $d, $a, $b` | XOR على مستوى البتات | `xor $t2, $t0, $t1` | `t2 = t0 ^ t1;` |
| `xori $t, $s, n` | XOR مع ثابت | `xori $t1, $t0, 0xFF` | `t1 = t0 ^ 0xFF;` |
| `not $d, $s` | NOT (عكس كل البتات) | `not $t2, $t0` | `t2 = ~t0;` |
| `sll $t, $s, n` | إزاحة يسار (ضرب في 2^n) | `sll $t1, $t0, 2` | `t1 = t0 << 2;` |
| `srl $t, $s, n` | إزاحة يمين (قسمة على 2^n) | `srl $t1, $t0, 2` | `t1 = t0 >> 2;` |
| `sra $t, $s, n` | إزاحة يمين حسابية (تحافظ على الإشارة) | `sra $t1, $t0, 2` | `t1 = t0 >> 2;` (signed) |

### 4.4. التعامل مع الذاكرة (Memory Access)

| الأمر | المعنى | مثال | C++ مقابل |
|-------|--------|------|-----------|
| `lw $t, label` | Load Word: RAM ← مسجل (4 بايت) | `lw $t0, x` | `t0 = x;` |
| `sw $t, label` | Store Word: مسجل → RAM (4 بايت) | `sw $t0, x` | `x = t0;` |
| `lw $t, offset($b)` | Load Word بعنوان `$b + offset` | `lw $t0, 0($s0)` | `t0 = arr[0];` |
| `sw $t, offset($b)` | Store Word بعنوان `$b + offset` | `sw $v0, 0($s0)` | `arr[0] = v0;` |
| `lb $t, offset($b)` | Load Byte (1 بايت) | `lb $t0, 0($s0)` | `char c = str[i];` |
| `sb $t, offset($b)` | Store Byte (1 بايت) | `sb $t0, 0($s0)` | `str[i] = c;` |
| `lbu $t, offset($b)` | Load Byte Unsigned | `lbu $t0, 0($s0)` | بدون تمديد إشارة |
| `lhu $t, offset($b)` | Load Halfword Unsigned | `lhu $t0, 0($s0)` | 2 بايت بدون إشارة |

### 4.5. الجمل الشرطية والقفز (Branch & Jump)

| الأمر | المعنى | مثال | C++ مقابل |
|-------|--------|------|-----------|
| `beq $a, $b, L` | إذا كان $a == $b اذهب إلى L | `beq $t0, $t1, label` | `if (a==b) goto L;` |
| `bne $a, $b, L` | إذا كان $a != $b اذهب إلى L | `bne $t0, $t1, label` | `if (a!=b) goto L;` |
| `bgt $a, $b, L` | إذا كان $a > $b اذهب إلى L | `bgt $t0, $t1, label` | `if (a>b) goto L;` |
| `bge $a, $b, L` | إذا كان $a >= $b اذهب إلى L | `bge $t0, $t1, label` | `if (a>=b) goto L;` |
| `blt $a, $b, L` | إذا كان $a < $b اذهب إلى L | `blt $t0, $t1, label` | `if (a<b) goto L;` |
| `ble $a, $b, L` | إذا كان $a <= $b اذهب إلى L | `ble $t0, $t1, label` | `if (a<=b) goto L;` |
| `beqz $r, L` | إذا كان $r == 0 اذهب إلى L | `beqz $t0, label` | `if (t0==0) goto L;` |
| `bnez $r, L` | إذا كان $r != 0 اذهب إلى L | `bnez $t0, label` | `if (t0!=0) goto L;` |
| `b L` | اذهب إلى L (قفزة غير مشروطة) | `b label` | `goto L;` |
| `j label` | Jump (قفزة بعيدة) | `j label` | `goto L;` |
| `jal label` | Jump And Link (استدعاء دالة) | `jal add` | `result = add();` |
| `jr $ra` | Jump Register (رجوع من دالة) | `jr $ra` | `return;` |

### 4.6. System Calls (استدعاءات النظام)

نضع رقم الخدمة في `$v0` والمعاملات في `$a0` (و `$a1` إن لزم) ثم ننفذ `syscall`.

| الرقم (`$v0`) | الخدمة | المعاملات | الوصف |
|:---:|--------|-----------|-------|
| 1 | print_int | `$a0` = الرقم | اطبع عدداً صحيحاً |
| 2 | print_float | `$f12` = الرقم | اطبع عدداً كسرياً |
| 3 | print_double | `$f12` = الرقم | اطبع عدداً كسرياً بدقة مضاعفة |
| 4 | print_string | `$a0` = عنوان النص | اطبع سلسلة نصية (حتى `\0`) |
| 5 | read_int | الناتج في `$v0` | اقرأ عدداً صحيحاً من المستخدم |
| 6 | read_float | الناتج في `$f0` | اقرأ عدداً كسرياً |
| 7 | read_double | الناتج في `$f0` | اقرأ عدداً كسرياً بدقة مضاعفة |
| 8 | read_string | `$a0` = عنوان المخزن, `$a1` = max length | اقرأ سلسلة نصية |
| 9 | sbrk (allocate) | `$a0` = عدد البايتات | احجز ذاكرة (الناتج في `$v0`) |
| 10 | exit | — | أنهِ البرنامج |
| 11 | print_char | `$a0` = الحرف (ASCII) | اطبع حرفاً واحداً |
| 12 | read_char | الناتج في `$v0` | اقرأ حرفاً واحداً |
| 30 | time | `$a0` = low 32 bits, `$a1` = high 32 bits | احصل على الوقت (مللي ثانية منذ 1970) |
| 34 | print_hex | `$a0` = الرقم | اطبع number بصيغة hexadecimal |

### أكثرها استخداماً:

```mips
li $v0, 4         # اطبع نص
la $a0, msg       # النص المراد طباعته
syscall

li $v0, 5         # اقرأ عدداً صحيحاً
syscall
move $t0, $v0     # احفظ القيمة المقروءة

li $v0, 1         # اطبع عدداً صحيحاً
move $a0, $t0     # الرقم المراد طباعته
syscall

li $v0, 10        # اخروج من البرنامج
syscall
```

## 5. أمثلة مبسّطة جداً — كل مثال يشرك概念اً واحداً فقط

### ◉ مثال A: ضع رقماً في مسجل (li) واطبعه

**الكود:**
```mips
li $t0, 5       # $t0 = 5
move $a0, $t0   # $a0 = $t0  (جهّز الرقم للطباعة)
li $v0, 1       # syscall 1 = اطبع عدداً صحيحاً
syscall         # نفّذ
```

| السطر | معناه |
|-------|-------|
| `li $t0, 5` | ضع الرقم 5 في المسجل `$t0` |
| `move $a0, $t0` | انسخ القيمة من `$t0` إلى `$a0` (لأن syscall يقرأ من `$a0`) |
| `li $v0, 1` | أخبر syscall أننا نريد خدمة "اطبع عدداً" |
| `syscall` | نفّذ الخدمة |

> C++ مقابل: `int a = 5; cout << a;`

---

### ◉ مثال B: اقرأ رقماً من المستخدم (syscall 5)

**الكود:**
```mips
li $v0, 5       # syscall 5 = اقرأ عدداً صحيحاً
syscall         # انتظر المستخدم ليكتب رقماً
move $t0, $v0   # $t0 = الرقم الذي أدخله المستخدم (النتيجة في $v0)
```

> **تذكرة:** syscall 5 يضع الرقم المقروء في `$v0`. انقله فوراً إلى مسجل آخر لأن `$v0` سيتغير مع أي syscall قادم.

> C++ مقابل: `cin >> t0;`

---

### ◉ مثال C: اطبع نصاً (syscall 4)

**الكود:**
```mips
.data
    msg: .asciiz "Hello"   # عرّف النص "Hello" في RAM

.text
    la $a0, msg            # $a0 = عنوان msg
    li $v0, 4              # syscall 4 = اطبع نصاً
    syscall                # اطبع "Hello"
```

| السطر | معناه |
|-------|-------|
| `.asciiz "Hello"` | احجز "Hello" في الذاكرة وأضف `\0` في نهايته |
| `la $a0, msg` | ضع عنوان (عنوان) النص في `$a0` |
| `li $v0, 4` | أخبر syscall أننا نريد "اطبع نصاً" |
| `syscall` | اطبع النص على الشاشة |

> C++ مقابل: `cout << "Hello";`

### ◉ مثال D: if — هل الرقم يساوي صفراً؟

**الكود:**
```mips
li $t0, 0          # $t0 = 0
beqz $t0, found    # إذا $t0 == 0 → اذهب إلى found
b not_found        # وإلا → اذهب إلى not_found

found:
    # نأتي إلى هنا فقط إذا $t0 == 0
    ...

not_found:
    # نأتي إلى هنا فقط إذا $t0 != 0
    ...
```

> `beqz` = Branch if Equal to Zero. إذا تحقق الشرط، نقفز إلى label.

> C++ مقابل: `if (t0 == 0) goto found; else goto not_found;`

---

### ◉ مثال E: if/else — هل الرقم موجب؟

**الكود:**
```mips
li $t0, 5              # $t0 = 5

ble $t0, $zero, else_part  # إذا $t0 <= 0 → اذهب إلى else_part
# هنا نأتي فقط إذا $t0 > 0
la $a0, msg_pos
li $v0, 4
syscall
b end_if                  # ← مهم: نتخطى else_part

else_part:
# هنا نأتي فقط إذا $t0 <= 0
la $a0, msg_neg
li $v0, 4
syscall

end_if:
```

> **لماذا `b end_if`؟** في MIPS، التنفيذ يستمر سطراً سطراً. إذا دخلنا `if`، يجب أن نقفز ونتخطى `else`، وإلا سينفذ `else` أيضاً!

> C++ مقابل: `if (t0 > 0) cout << "Positive"; else cout << "Negative";`

---

### ◉ مثال F: حلقة for — اطبع الأعداد 1, 2, 3, 4, 5

**الكود:**
```mips
li $t0, 1           # $t0 = 1  (هذا هو العداد i)

loop:
    bgt $t0, 5, exit    # إذا $t0 > 5 → اخرج من الحلقة

    move $a0, $t0       # اطبع قيمة $t0
    li $v0, 1
    syscall

    addi $t0, $t0, 1    # $t0 = $t0 + 1  (i++)
    b loop              # ارجع إلى loop

exit:
    li $v0, 10
    syscall
```

**شرح الحلقة:**
```
li $t0, 1           ← تهيئة: i = 1
loop:               ← علامة البداية
bgt $t0, 5, exit    ← شرط: إذا i > 5 → توقف
... body ...        ← جسم الحلقة
addi $t0, $t0, 1    ← تحديث: i++
b loop              ← عد إلى البداية
```

> C++ مقابل: `for (int i = 1; i <= 5; i++) cout << i;`

---

### ◉ مثال G: حلقة while — مجموع 1+2+3+...+N

**الكود:**
```mips
.data
    prompt: .asciiz "Enter N: "
    result: .asciiz "Sum = "
.text
main:
    la $a0, prompt      # اطبع "Enter N: "
    li $v0, 4
    syscall
    li $v0, 5           # اقرأ N
    syscall
    move $t1, $v0       # $t1 = N

    li $t2, 1           # $t2 = i  (عداد)
    li $t3, 0           # $t3 = sum

loop:
    bgt $t2, $t1, done  # إذا i > N → اخرج
    add $t3, $t3, $t2   # sum = sum + i
    addi $t2, $t2, 1    # i++
    b loop

done:
    la $a0, result
    li $v0, 4
    syscall
    move $a0, $t3
    li $v0, 1
    syscall
```

> C++ مقابل:
> ```cpp
> int N; cin >> N;
> int sum = 0, i = 1;
> while (i <= N) { sum += i; i++; }
> cout << sum;
> ```

### ◉ مثال H: مصفوفة — خزّن رقماً في arr[0]

**الكود:**
```mips
.data
    arr: .space 20      # 20 بايت = 5 أعداد

.text
    la $s0, arr         # $s0 = عنوان أول عنصر في arr
    li $t0, 99          # $t0 = 99 (القيمة التي نريد تخزينها)

    sw $t0, 0($s0)      # arr[0] = 99  (خزّن 99 في أول 4 بايت)
```

| السطر | معناه |
|-------|-------|
| `.space 20` | احجز 20 بايت (5 أعداد × 4 بايت) |
| `la $s0, arr` | `$s0` = عنوان أول عنصر (base address) |
| `sw $t0, 0($s0)` | اكتب قيمة `$t0` في الذاكرة عند `$s0 + 0` |

> C++ مقابل: `int arr[5]; arr[0] = 99;`

---

### ◉ مثال I: مصفوفة — اقرأ قيمة من arr[2]

```mips
.data
    arr: .space 20
.text
    la $s0, arr

    li $t0, 2           # $t0 = index = 2
    sll $t1, $t0, 2     # $t1 = 2 × 4 = 8  (الإزاحة)
    add $t1, $s0, $t1   # $t1 = &arr[0] + 8 = عنوان arr[2]
    lw $t2, 0($t1)      # $t2 = arr[2]  (اقرأ 4 بايت)
```

**شرح الوصول لمصفوفة:**
```
arr[i]:
  sll $t1, $i, 2      # offset = i × 4
  add $t1, $base, $t1 # addr = &arr[0] + offset
  lw/sw $val, 0($t1)  # arr[i] = val / val = arr[i]
```

> C++ مقابل: `int x = arr[2];`

---

### ◉ مثال J: دالة — اجمع رقمين

**الكود:**
```mips
.text
main:
    li $a0, 5           # $a0 = 5  (المعامل الأول)
    li $a1, 3           # $a1 = 3  (المعامل الثاني)
    jal add_func        # استدعِ الدالة ← يحفظ $ra ويقفز

    move $a0, $v0       # $v0 يحتوي على النتيجة (8)
    li $v0, 1
    syscall
    li $v0, 10
    syscall

add_func:
    add $v0, $a0, $a1   # $v0 = $a0 + $a1  (النتيجة)
    jr $ra              # ارجع (استخدم $ra لتعرف أين ترجع)
```

| المصطلح | المعنى | C++ مقابل |
|---------|--------|-----------|
| `$a0, $a1` | معاملات الدالة (arguments) | `add(5, 3)` |
| `$v0` | قيمة الإرجاع (return value) | `return a + b;` |
| `jal label` | استدعِ الدالة + احفظ عنوان الرجوع | `result = add(...)` |
| `jr $ra` | ارجع إلى العنوان المحفوظ | `return` |
| `$ra` | عنوان الرجوع (يحفظه jal تلقائياً) | — |

### ◉ مثال K: دالة مع مكدس —  factorial

**لماذا نحتاج المكدس؟** لأن `jal` يغير `$ra`. إذا استدعت دالة دالة أخرى، نخسر عنوان الرجوع الأول. الحل: نحفظ `$ra` في المكدس.

```mips
factorial:
    addi $sp, $sp, -8   # احجز 8 بايت في المكدس
    sw $ra, 0($sp)      # احفظ $ra
    sw $a0, 4($sp)      # احفظ $a0

    li $t0, 1
    ble $a0, $t0, base  # if n <= 1 → base case
    addi $a0, $a0, -1   # n - 1
    jal factorial       # استدعِ نفسها (رجعياً)
    lw $a0, 4($sp)      # استرجع $a0
    mul $v0, $a0, $v0   # n * factorial(n-1)
    b return_fact

base:
    li $v0, 1

return_fact:
    lw $ra, 0($sp)      # استرجع $ra
    addi $sp, $sp, 8    # حرّر المكدس
    jr $ra
```

| العملية | الكود | الشرح |
|---------|-------|-------|
| حجز مساحة | `addi $sp, $sp, -8` | حرّك مؤشر المكدس لأسفل (احجز مكاناً) |
| حفظ | `sw $ra, 0($sp)` | احفظ القيمة في المكدس |
| استرجاع | `lw $ra, 0($sp)` | أعد القيمة من المكدس |
| تحرير | `addi $sp, $sp, 8` | حرّك مؤشر المكدس لأعلى (حرّر المكان) |

> C++ مقابل:
> ```cpp
> int factorial(int n) {
>     if (n <= 1) return 1;
>     return n * factorial(n - 1);
> }
> ```

### ◉ مثال L: سلسلة نصية — احسب طولها

**الكود:**
```mips
.data
    str: .asciiz "hello"

.text
    la $t0, str         # $t0 = عنوان أول حرف
    li $t1, 0           # $t1 = length = 0

loop:
    lb $t2, 0($t0)      # اقرأ الحرف الحالي (بايت واحد)
    beqz $t2, done      # إذا الحرف = 0 (\0) → انتهى
    addi $t1, $t1, 1    # length++
    addi $t0, $t0, 1    # انتقل للحرف التالي
    b loop

done:
    move $a0, $t1       # اطبع الطول
    li $v0, 1
    syscall
```

| السطر | معناه |
|-------|-------|
| `la $t0, str` | `$t0 = &str[0]` (عنوان الحرف الأول) |
| `lb $t2, 0($t0)` | `$t2 = *t0` (اقرأ حرفاً واحداً من الذاكرة) |
| `beqz $t2, done` | إذا الحرف = `\0` (قيمته 0) → النص انتهى |
| `addi $t0, $t0, 1` | انتقل إلى الحرف التالي (`$t0++`) |

> C++ مقابل:
> ```cpp
> char str[] = "hello";
> int len = 0;
> while (str[len] != '\0') len++;
> ```

## 6. الفروقات الأساسية بين MIPS Assembly و C++

| المفهوم | MIPS | C++ |
|---------|------|-----|
| المتغيرات | Labels في `.data` أو مسجلات | `int x;` |
| العمليات | كل عملية سطر واحد | `x = a + b;` |
| if/else | `beq`/`bgt`/`b` مع labels | `if (x > 0) { }` |
| الحلقات | `bge`/`b` مع labels | `for/while` |
| المصفوفات | `sll` + `add` + `lw`/`sw` | `arr[i]` |
| الدوال | `jal`/`jr` + المكدس | `func()` |
| الإدخال/الإخراج | `syscall` | `cin`/`cout` |
| لا شيء مضمون | كل شيء تتحكم فيه أنت | garbage collector, bounds checking |

## 7. ملخص سريع (Cheat Sheet) — أكثر 20 أمراً استخداماً

| # | الأمر | ماذا يفعل |
|:--:|-------|-----------|
| 1 | `li $t, n` | ضع رقماً في المسجل |
| 2 | `la $t, label` | ضع عنواناً من RAM في المسجل |
| 3 | `add $d, $a, $b` | جمع |
| 4 | `sub $d, $a, $b` | طرح |
| 5 | `addi $t, $s, n` | جمع مع ثابت |
| 6 | `mul $d, $a, $b` | ضرب |
| 7 | `div $a, $b` | قسمة |
| 8 | `mflo $d` | اجلب ناتج القسمة |
| 9 | `mfhi $d` | اجلب باقي القسمة |
| 10 | `lw $t, label/offset($b)` | اقرأ من RAM إلى مسجل (4 بايت) |
| 11 | `sw $t, label/offset($b)` | اكتب من مسجل إلى RAM (4 بايت) |
| 12 | `lb $t, offset($b)` | اقرأ من RAM إلى مسجل (1 بايت) |
| 13 | `sb $t, offset($b)` | اكتب من مسجل إلى RAM (1 بايت) |
| 14 | `beq $a, $b, L` | اذهب إلى L إذا تساويا |
| 15 | `bne $a, $b, L` | اذهب إلى L إذا اختلفا |
| 16 | `bgt $a, $b, L` | اذهب إلى L إذا كان الأول أكبر |
| 17 | `blt $a, $b, L` | اذهب إلى L إذا كان الأول أصغر |
| 18 | `b L` | اذهب إلى L (دون شرط) |
| 19 | `jal L` | استدع دالة |
| 20 | `jr $ra` | ارجع من دالة |
