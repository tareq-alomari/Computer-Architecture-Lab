# المحاضرة الثامنة: السلاسل النصية

---

## شرح كل أمر

### ASCII Chart (مهم)

| الحرف | القيمة | ملاحظة |
|-------|:------:|--------|
| `'A'` | 65 | |
| `'Z'` | 90 | |
| `'a'` | 97 | |
| `'z'` | 122 | |
| `'0'` | 48 | |
| `'\n'` | 10 | سطر جديد |
| `'\0'` | 0 | نهاية النص (null) |

الفرق بين `a` و `A` = 32 (97 - 65 = 32). حرف صغير - 32 = حرف كبير.

### `str: .asciiz "hello"`

- **`.asciiz`** = ASCII + Zero-terminated
- يحجز النص "hello" في RAM ويضيف `\0` (رقم 0) في الآخر
- في الذاكرة: `h` `e` `l` `l` `o` `\0` (6 بايت)
- الـ `\0` مهم جداً — هو الذي يقول "النص انتهى هنا"

### `lb $t2, 0($t0)`

- **lb** = Load Byte (احمل بايت واحد)
- يقرأ بايت واحد (8 bits = حرف واحد) من RAM
- في C++: `char c = str[i];`
- `lw` تقرأ 4 بايت, `lb` تقرأ بايت واحد

### `sb $t2, 0($t0)`

- **sb** = Store Byte (خزّن بايت واحد)
- يحفظ بايت واحد في RAM
- في C++: `str[i] = c;`

### `beqz $t2, done_len`

إذا كان الحرف = 0 (أي `\0`), اذهب إلى `done_len`. هذه هي الطريقة التي نعرف بها أن النص انتهى.
في `strlen` نعد الحروف إلى أن نجد `\0`.

### `addi $t2, $t2, -32`

`'a' = 97`, `'A' = 65`, الفرق = 32. حرف صغير - 32 = حرف كبير.
في C++: `c = c - 32;` (أو `c -= 32`)

## الكود

```mips
.data
    str: .asciiz "hello"          # "hello" + \0
    msg_len: .asciiz "Length = "
    msg_up:  .asciiz "Uppercase: "
    newline: .asciiz "\n"

.text
main:
    # ========================================
    # مثال L: strlen — احسب طول النص
    # C++:
    #   char str[] = "hello";
    #   int len = 0;
    #   while (str[len] != '\0') len++;
    # ========================================
    la $a0, msg_len
    li $v0, 4
    syscall

    la $t0, str                  # $t0 = عنوان أول حرف
    li $t1, 0                    # $t1 = length = 0

len_loop:
    lb $t2, 0($t0)               # اقرأ الحرف الحالي  (C++: char c = str[i];)
    beqz $t2, done_len           # إذا \0 → انتهى

    addi $t1, $t1, 1             # length++
    addi $t0, $t0, 1             # انتقل للحرف التالي
    b len_loop

done_len:
    move $a0, $t1
    li $v0, 1
    syscall
    la $a0, newline
    li $v0, 4
    syscall

    # ========================================
    # مثال: تحويل الأحرف الصغيرة → كبيرة
    # C++:
    #   for (int i = 0; str[i]; i++)
    #       if (str[i] >= 'a' && str[i] <= 'z')
    #           str[i] -= 32;
    # الفرق: 'a'(97) - 'A'(65) = 32
    # ========================================
    la $a0, msg_up
    li $v0, 4
    syscall

    la $t0, str

upper_loop:
    lb $t2, 0($t0)
    beqz $t2, done_upper

    li $t3, 97                   # 'a'
    blt $t2, $t3, skip           # إذا الحرف < 'a' → تجاوز
    li $t3, 122                  # 'z'
    bgt $t2, $t3, skip           # إذا الحرف > 'z' → تجاوز

    addi $t2, $t2, -32           # c - 32 = حرف كبير  (C++: c -= 32;)
    sb $t2, 0($t0)               # اكتب الحرف مكانه

skip:
    addi $t0, $t0, 1
    b upper_loop

done_upper:
    la $a0, str
    li $v0, 4
    syscall

    li $v0, 10
    syscall
```

## خلاصة التعليمات الجديدة

| الأمر | المعنى | C++ مقابل |
|-------|--------|-----------|
| `lb $t, addr` | Load Byte: اقرأ بايت واحد من RAM | `char c = str[i]` |
| `sb $t, addr` | Store Byte: خزّن بايت واحد في RAM | `str[i] = c` |
| `.asciiz` | نص + `\0` تلقائياً | `char str[] = "..."` |
| `\0` = 0 | نهاية النص | null terminator |

### تحويل الحروف

| من | إلى | العملية |
|----|-----|---------|
| `'a'` (97) | `'A'` (65) | `- 32` |
| `'z'` (122) | `'Z'` (90) | `- 32` |
| `'A'` (65) | `'a'` (97) | `+ 32` |
