# قبل المحاضرة الأولى: أساسيات الحاسوب

> هذا الملف يشرح المفاهيم الأساسية لفهم لغة التجميع (Assembly).
> اقرؤه قبل فتح أي كود MIPS.

---

## 1. كيف يعمل الحاسوب؟

للحاسوب ثلاثة مكونات رئيسية:

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│   CPU    │◄───►│   RAM    │     │   I/O    │
│ (معالج)  │     │ (ذاكرة)  │     │(شاشة/لوحة)│
└──────────┘     └──────────┘     └──────────┘
```

- **CPU (المعالج)**: هو دماغ الحاسوب. ينفذ الأوامر.
  - يحتوي على **مسجّلات (Registers)**: 32 مخزناً صغيراً داخله
  - يجلب الأوامر من RAM وينفذها واحداً واحداً
  - كل أمر بسيط جداً: "اجمع"، "اطرح"، "اجلب من الذاكرة"

- **RAM (الذاكرة)**: مكان تخزين البيانات والأوامر.
  - عبارة عن عناوين (Addresses) لكل عنوان قيمة
  - أبطأ بكثير من المسجّلات
  - `0x10010000` ← القيمة 42
  - `0x10010004` ← القيمة 100

- **I/O (الإدخال/الإخراج)**: الشاشة، لوحة المفاتيح، الفأرة...
  - لطلب خدمة منهم، نستخدم `syscall`

## 2. النظام الثنائي (Binary) — لماذا 0 و 1 فقط؟

الكهرباء داخل الحاسوب: إما مشغّلة **(1)** أو مطفأة **(0)**.
لا توجد أرقام 2 أو 3 أو 5 — فقط 0 و 1.

أي رقم يمكن كتابته بـ 0 و 1:

| عشري | ثنائي | الشرح |
|:----:|:-----:|-------|
| 0 | 0 | |
| 1 | 1 | |
| 2 | 10 | (1×2 + 0×1) |
| 3 | 11 | (1×2 + 1×1) |
| 4 | 100 | (1×4 + 0×2 + 0×1) |
| 5 | 101 | (1×4 + 0×2 + 1×1) |

**الخانات في النظام الثنائي:**

| 8 | 4 | 2 | 1 |
|---|---|---|---|
| 1 | 0 | 1 | 1 |

الرقم `1011` في الثنائي = 1×8 + 0×4 + 1×2 + 1×1 = **11**

## 3. النظام السداسي عشر (Hexadecimal) — اختصار للثنائي

الأرقام الكبيرة في Binary طويلة:
- الرقم 42 = `00101010` (8 خانات)
- الرقم 1,000,000 = `11110100001001000000` (20 خانة)

للاختصار، نستخدم **Hexadecimal** (أساسه 16):

| عشري | 0-9 | 10 | 11 | 12 | 13 | 14 | 15 |
|:----:|:---:|:--:|:--:|:--:|:--:|:--:|:--:|
| **Hex** | 0-9 | A | B | C | D | E | F |

كل خانة Hex = 4 خانات Binary:
```
Binary:  0010 1010
Hex:       2    A   = 0x2A = 42
```

نكتب `0x` قبل الرقم للدلالة على أنه Hex:
- `0x2A` = 42
- `0xFF` = 255
- `0x12345678` = 305,419,896
- `0x10010000` = عنوان في الذاكرة

**لماذا نستخدم Hex في Assembly؟**
- عناوين الذاكرة تظهر كـ Hex (`0x10010000`)
- القيم 32-bit أسهل قراءة كـ Hex
- القناع (mask) نكتبه كـ Hex (`0xFF`)

## 4. البت (Bit) والبايت (Byte) والكلمة (Word)

| الوحدة | الحجم | الوصف |
|--------|-------|-------|
| **Bit** | 1 bit | أصغر وحدة. قيمته 0 أو 1 |
| **Byte** | 8 Bits | مثال: `10101010` |
| **Word** | 4 Bytes = 32 Bits | حجم قياسي في MIPS |

تخزين البيانات في الذاكرة:
```
Byte: | 01010101 |          (8 bits)
Word: | 01010101 | 01010101 | 01010101 | 01010101 |
      |__بايت 1__||__بايت 2__||__بايت 3__||__بايت 4__|
      |_______________ 32 bits (1 Word) ______________|
```

## 5. لغة الآلة (Machine Language) — ما يفهمه CPU

**المعالج لا يفهم** `la $a0, msg` — هذا كود للبشر.
المعالج يفهم **0 و 1 فقط**.

لغة الآلة = تعليمات بشكل 0 و 1:
```
مثال: "اجمع $t0 مع $t1"
  Binary: 000000 01000 01001 01010 00000 100000
  Hex:    0x012A4820
```

نحن لا نكتب بهذا الشكل! نكتب **Assembly**:
```mips
add $t0, $t1, $t2
```

ثم برنامج اسمه **Assembler** (في حالتنا MARS) يحولها إلى 0 و 1 التي يفهمها CPU.

**الخلاصة:**
```
كود MIPS (.asm)  ──►  Assembler (MARS)  ──►  Machine Code (0/1)  ──►  CPU
```

## 6. دورة تنفيذ الأمر (Fetch-Execute Cycle)

المعالج ينفذ كل أمر في 3 خطوات:

1. **Fetch**: اجلب الأمر من RAM
2. **Decode**: افهم ماذا يفعل هذا الأمر
3. **Execute**: نفذه

**مثال:**
```
المعالج رأى:  0x012A4820
فهم أنه:      add $t0, $t1, $t2
نفذ:          $t0 = $t1 + $t2
```

**PC (Program Counter)**:
PC هو مسجل خاص داخل CPU يحفظ عنوان الأمر الذي سيعمل عليه حالياً. بعد كل أمر، PC يزيد ليشير إلى الأمر التالي.

## 7. كيف يُنفّذ برنامج C++ على CPU؟

```
  // C++ Code
  int main() {
      int x = 5;
      int y = x + 3;
      return 0;
  }
       │
       ▼  (Compiler يحولها)
       
  // Assembly
  li $t0, 5        # x = 5
  addi $t1, $t0, 3 # y = x + 3
   li $v0, 10       # اخروج من البرنامج
  syscall
       │
       ▼  (Assembler يحولها)
       
  // Machine Language (0 و 1)
  00100100000010000000000000000101
  00100001001010000000000000000011
  00100100000000100000000000001010
  00000000000000000000000000001100
       │
       ▼  (CPU ينفذ)
       
  النتيجة: y = 8
```

## 8. كيف تعمل المسجّلات (Registers)؟

**المسجل (Register)** = مخزن صغير داخل CPU (32 بت = 4 بايت).

MIPS يحتوي على 32 مسجلاً:

| الاسم | الرقم | الاستخدام |
|-------|:-----:|-----------|
| `$zero` | 0 | دائماً 0 |
| `$t0` - `$t9` | 8-15, 24-25 | مؤقت (Temporary) |
| `$s0` - `$s7` | 16-23 | محفوظ (Saved) |
| `$a0` - `$a3` | 4-7 | وسائط (Arguments) |
| `$v0` - `$v1` | 2-3 | قيم الإرجاع (Return Values) |
| `$sp` | 29 | مؤشر المكدس (Stack Pointer) |
| `$ra` | 31 | عنوان العودة (Return Address) |
| `$gp` | 28 | المؤشر العام (Global Pointer) |
| `$fp` | 30 | مؤشر الإطار (Frame Pointer) |

الفرق بين المتغير في C++ والمسجل في Assembly:
```cpp
C++:    int x = 5;          // x في RAM
ASM:    li $t0, 5           // قيمة 5 في المسجل $t0 داخل CPU
```

`$t0` **ليس متغيراً** — هو مكان **فيزيائي** داخل المعالج. يمكن رؤيته في نافذة Registers في MARS.

## 9. المفاهيم المطلوبة قبل المحاضرة الأولى

| المفهوم | المعنى |
|---------|--------|
| **CPU** | معالج، ينفذ الأوامر |
